# 🎓 SmartEval - Secure Proctored Quiz Platform

SmartEval is a high-performance, full-stack examination system designed to ensure academic integrity while providing a seamless user experience. It empowers faculty to manage assessments efficiently and provides students with a secure, NTA-style exam environment.

---

## 🌟 Core Modules & Features

### 👨‍🏫 Faculty Dashboard (Exam Orchestration)

- **Dynamic Quiz Builder**  
  Create quizzes with custom titles, descriptions, and durations.

- **Time-Window Scheduling**  
  Set precise start and end times to control quiz access.

- **Centralized Question Bank**  
  Manage reusable questions for faster exam creation.

- **Live Analytics**  
  Real-time score distribution visualization using Chart.js.

- **Incident Monitoring**  
  Track tab-switching events with proctoring logs.

- **Leaderboard**  
  Auto-generated rankings based on performance.

---

### 🎓 Student Interface (Seamless Experience)

- **Professional Exam UI**  
  NTA-style interface with live timer and question palette.

- **Performance Tracking**  
  View past attempts with percentage scores.

- **Instant Feedback**  
  Get results immediately after submission.

- **Automated Submission**  
  Auto-submit when time expires (fail-safe mechanism).

---

## 🛡️ Smart Proctoring & Security

- **Tab-Switch Detection**  
  Detect and log suspicious behavior in real-time.

- **Strict Access Control**  
  Prevent access to inactive or expired quizzes.

- **JWT Authentication & RBAC**  
  Secure role-based access control for users.

---

## 🛠️ Technical Architecture

| Layer       | Technology |
|------------|------------|
| Frontend   | React.js (Vite), Tailwind CSS, Chart.js, React Router |
| Backend    | Java, Spring Boot, Spring Security, Hibernate/JPA |
| Security   | JSON Web Token (JWT) |
| Database   | MySQL / H2 |
| Tooling    | Maven, Git, Postman |
